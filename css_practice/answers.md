# Ответы на вопросы для самоконтроля

## 1. Разница между селектором по классу и по ID

| Критерий | Класс (`.class`) | ID (`#id`) |
|----------|------------------|------------|
| Специфичность | 0-1-0 | 1-0-0 |
| Повторное использование | Да, на многих элементах | Нет, только один на странице |
| Применение | Стилизация групп элементов | Уникальные элементы |

Класс предпочтительнее для стилизации, ID — для якорей, JS-хуков, уникальных блоков.

## 2. Как работает каскад

Каскад — механизм разрешения конфликтов между правилами. Порядок применения:
1. Важность (`!important` > обычные)
2. Происхождение (автор > пользователь > браузер)
3. Специфичность (чем выше, тем приоритетнее)
4. Порядок в файле (кто ниже — тот побеждает при равной специфичности)

## 3. Расчёт специфичности

| Селектор | Специфичность |
|----------|---------------|
| `ul li.important` | 0-1-2 |
| `#site-title` | 1-0-0 |
| `.content > .featured-post` | 0-2-0 |

## 4. Наследуемые и ненаследуемые свойства

**Наследуемые:** `color`, `font-family`, `font-size`, `line-height`, `text-align`.
**Ненаследуемые:** `margin`, `padding`, `border`, `background`, `width`.

## 5. Селектор `>` vs потомков (пробел)

- `div p` — все `p` внутри `div` на любой глубине.
- `div > p` — только прямые дочерние `p` внутри `div`.

## 6. Псевдоклассы `:hover` и `:nth-child()`

- `:hover` — стили при наведении: кнопки, ссылки, карточки.
- `:nth-child()` — выбор по порядку: зебра-таблицы, списки, галереи.

## 7. Правило `!important`

Принудительно повышает приоритет правила. Использовать с осторожностью, потому что:
- ломает естественный каскад;
- усложняет отладку;
- трудно переопределить.

## 8. Псевдоэлементы `::before` и `::after`

Добавляют контент до/после элемента. Могут содержать текст, иконки (через `content`), декоративные элементы. Не попадают в DOM.

## 10. DevTools для отладки CSS

- Elements → Styles — примененные/переопределённые стили.
- Computed — итоговые значения.
- Toggle state — принудительные `:hover`, `:focus`.
- Изменение в реальном времени — быстрая проверка гипотез.
- Проверка наследования — вкладка Inherited.
