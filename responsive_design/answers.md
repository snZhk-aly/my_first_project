# Ответы на вопросы для самоконтроля — Практическая работа №6

## 1. Что такое Viewport meta tag и почему он важен для адаптивного дизайна?

Это мета-тег в head HTML-документа:
<meta name="viewport" content="width=device-width, initial-scale=1.0">

Он говорит браузеру мобильного устройства: «считай ширину страницы равной ширине экрана, масштаб — 1 к 1». Без него телефон притворяется, что он шириной 980px, и показывает страницу мелкой, как на десктопе. Без viewport никакая адаптивная вёрстка не работает.


## 2. Какие основные подходы к созданию адаптивных макетов вы использовали?

- Fluid (резиновый) — размеры в процентах, vw, fr, контент растягивается вместе с окном. Использован в hero, cards, gallery.
- Adaptive (адаптивный) — есть фиксированные брейкпоинты, макет переключается на другом размере. Использован через @media (max-width: 1024px, 768px, 480px).
- Responsive (отзывчивый) — комбинация первого и второго: резиновая основа + брейкпоинты там, где нужно перестроить. В работе применён именно этот подход.


## 3. Как работает Mobile First и в чём его преимущества перед Desktop First?

Mobile First — сначала пишем стили для мобильных, потом через @media (min-width: …) добавляем правила для больших экранов.

Преимущества:
- Меньше кода: базовые стили простые, добавляем только то, что нужно большим экранам.
- Быстрее загрузка на мобильных — главный сценарий.
- Легче поддерживать: один источник истины.
- Хорошо сочетается с прогрессивным улучшением.

Desktop First — наоборот, сначала десктоп, потом через max-width упрощаем. Тоже рабочий подход, но часто даёт больше кода и сложнее в поддержке.


## 4. Какие единицы измерения наиболее предпочтительны для адаптивной вёрстки и почему?

- % — относительно родителя, хорошо для ширин.
- rem — относительно корневого шрифта, удобно для отступов и размеров текста (не зависит от родителя).
- em — относительно родительского шрифта, удобно для внутренних отступов компонента.
- vw / vh — относительно окна просмотра, хорошо для баннеров.
- clamp() — комбинирует min, preferred, max — идеально для адаптивной типографики.
- fr в Grid — доли свободного места.

Фиксированный px тоже применяется, но не как единственная единица.


## 5. Как функция clamp() помогает создавать адаптивную типографику?

clamp(минимум, предпочтительное значение, максимум) — плавно меняет размер между минимумом и максимумом.

Пример:
font-size: clamp(16px, 2.5vw, 24px);

На узком экране — 16px, на широком — 24px, между ними — пропорционально ширине окна. Не нужны медиа-запросы для шрифта, и текст всегда читаемый.


## 6. Какие основные брейкпоинты вы использовали и как определили эти значения?

- 1024px — планшеты в горизонтальной ориентации, небольшие ноутбуки.
- 768px — планшеты в вертикальной ориентации, крупные телефоны.
- 480px — маленькие мобильные.

Значения выбраны по типовым размерам популярных устройств и по тому, где макет начинал ломаться. Брейкпоинты лучше ставить там, где дизайн реально требует изменений, а не подгонять под конкретные модели.


## 7. Как медиа-запросы @media помогают создавать адаптивные стили? Пример синтаксиса.

@media включает блок CSS при выполнении условия — например, при определённой ширине экрана.

Пример:
@media (max-width: 768px) {
  .nav { display: none; }
  .burger { display: flex; }
}

Внутри фигурных скобок — обычные CSS-правила. Они применяются только тогда, когда ширина окна не больше 768px. Так один и тот же HTML выглядит по-разному на разных устройствах.


## 8. В чём разница между max-width и min-width в медиа-запросах?

max-width: 768px — стили применяются, если ширина окна НЕ БОЛЬШЕ 768px. Используется в Desktop First.

min-width: 768px — стили применяются, если ширина окна НЕ МЕНЬШЕ 768px. Используется в Mobile First.

max-width удобен, когда основа — десктопная вёрстка и её нужно упрощать.
min-width удобен, когда основа — мобильная вёрстка и её нужно расширять.


## 9. Как сделать изображения адаптивными и какие CSS-свойства для этого используются?

- max-width: 100%; — картинка не вылезет за родителя.
- height: auto; — сохраняет пропорции.
- object-fit: cover / contain — управляет обрезкой внутри контейнера.
- aspect-ratio — задаёт соотношение сторон.
- width: 100%; — растягивает по родителю.

HTML-инструменты:
- srcset и sizes — разные картинки для разных разрешений.
- <picture> — разные форматы или кадрирование.
- loading="lazy" — ленивая загрузка.


## 10. Какие инструменты браузера помогают тестировать и отлаживать адаптивный дизайн?

- DevTools → режим адаптивного дизайна (Ctrl+Shift+M в Chrome/Firefox).
- Список предустановленных устройств (iPhone, iPad, Galaxy и др.).
- Ручное изменение размеров окна.
- Панель Layout — подсветка Flex/Grid.
- Инспектор стилей — видно, какие медиа-запросы сработали.
- Throttling — эмуляция медленной сети.
- Device Pixel Ratio — эмуляция Retina.
