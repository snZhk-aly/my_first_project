# Ответы на вопросы для самоконтроля — Практическая работа №11

## 1. В чём разница между innerHTML и textContent и когда следует использовать каждый метод?

- `innerHTML` — читает/записывает HTML-содержимое вместе с тегами. Браузер парсит строку как HTML. **Опасно**, если строка пришла от пользователя — возможна XSS-атака.
- `textContent` — читает/записывает только текст, теги игнорируются. **Безопасно** для вставки пользовательских данных.

Когда какой:
- `textContent` — по умолчанию для текста.
- `innerHTML` — если действительно нужно вставить разметку (например, шаблон с тегами из доверенного источника).

## 2. Как работает делегирование событий и какие преимущества даёт?

Делегирование — это когда один обработчик вешается на родителя, а не на каждого ребёнка. Событие от ребёнка всплывает к родителю, и там его ловят через `event.target`.

Преимущества:
- Меньше обработчиков — лучше производительность.
- Работает для элементов, добавленных **после** навешивания обработчика.
- Упрощает код при удалении/пересоздании элементов.

В работе использовано в `setupListEvents` — клики по кнопкам удаления ловятся через `list.addEventListener`.

## 3. Разница между getElementById, querySelector и querySelectorAll.

- `getElementById('id')` — ищет по id, возвращает один элемент или `null`. Самый быстрый.
- `querySelector('CSS-селектор')` — ищет по CSS-селектору, возвращает первый найденный элемент или `null`.
- `querySelectorAll('CSS-селектор')` — возвращает **NodeList** всех подходящих элементов (по нему можно проходить через `forEach`).

`getElementById` — когда есть id. `querySelector` — когда нужен сложный селектор или класс. `querySelectorAll` — когда нужно несколько элементов.

## 4. Как предотвратить стандартное поведение и когда это нужно?

`event.preventDefault()` отменяет дефолтное действие браузера.

Когда нужно:
- Отмена отправки формы для собственной валидации (`submit`).
- Отмена перехода по ссылке (например, если ссылка используется как кнопка).
- Отмена контекстного меню (`contextmenu`) для собственного.
- Блокировка чекбокса или клавиш.

В работе применено в `handleFormSubmit` — чтобы форма не перезагружала страницу.

## 5. В чём разница между classList.add() и className?

- `element.className = 'a b'` — полностью перезаписывает строку с классами. Если там были другие классы — они потеряются.
- `element.classList.add('a')` / `remove` / `toggle` / `contains` — точечные операции, не затрагивают остальные классы. Возвращают удобные методы.

Для управления отдельными классами всегда лучше `classList`. `className` — если нужно заменить все классы разом.
