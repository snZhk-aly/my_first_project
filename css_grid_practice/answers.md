# Ответы на вопросы для самоконтроля — Практическая работа №5

## 1. Какое основное свойство включает CSS Grid и чем принципиально отличается от Flexbox?

CSS Grid включается свойством display: grid (или display: inline-grid).

Принципиальное отличие: Flexbox — одномерный (элементы выстраиваются вдоль одной оси — строки или столбца). Grid — двумерный (одновременно управляет и строками, и столбцами). Flexbox подходит для выстраивания элементов в линию, Grid — для построения сложных макетов страниц целиком.


## 2. В чём разница между grid-template-columns и grid-auto-columns?

grid-template-columns задаёт размеры столбцов, которые явно описаны в шаблоне сетки.
grid-auto-columns задаёт размер для столбцов, которые создаются автоматически, если элементов больше, чем помещается в заданные столбцы.

grid-template-columns используется, когда структура известна заранее. grid-auto-columns — когда количество элементов заранее неизвестно, и они должны «достраивать» сетку.


## 3. Что делают функции repeat(), minmax() и auto-fit в grid-шаблоне?

repeat(количество, размер) — повторяет столбцы или строки. Пример: repeat(3, 1fr) создаёт три равных столбца.

minmax(min, max) — задаёт минимальный и максимальный размер. Пример: minmax(200px, 1fr) — столбец не меньше 200px и растягивается до 1fr.

auto-fit — автоматически подбирает количество столбцов под ширину контейнера. Пример:
grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));
— создаёт столько столбцов по 200px минимум, сколько влезает, и растягивает их.


## 4. Как работают именованные grid-области и какие преимущества они дают?

Именованные области задаются через grid-template-areas, а элементы привязываются к ним через grid-area.

Пример:
grid-template-areas:
  "header header"
  "sidebar main"
  "footer footer";

.header { grid-area: header; }

Преимущества:
- Макет виден прямо в CSS — легко читать.
- Переставлять блоки можно, просто меняя расположение строк в grid-template-areas.
- Не нужно считать линии сетки.
- Удобно для адаптивности: на мобильных можно переопределить areas.


## 5. Объясните систему нумерации grid-линий и как с помощью grid-column и grid-row размещать элементы.

Линии сетки нумеруются, начиная с 1, вдоль каждой оси: вертикальные линии — для столбцов, горизонтальные — для строк. Между линиями находятся ячейки.

Элемент размещается так:
grid-column: 1 / 3; — от первой вертикальной линии до третьей (занимает 2 столбца).
grid-row: 2 / 4; — от второй горизонтальной до четвёртой (занимает 2 строки).

Можно использовать span: grid-column: span 2; — занять 2 столбца.


## 6. Что такое grid-gap (или gap) и чем он лучше margins для создания промежутков в сетке?

gap (раньше grid-gap) задаёт промежутки между строками и столбцами сетки. Можно писать gap: 16px; или отдельно row-gap и column-gap.

Преимущества перед margin:
- Не нужно убирать margin у крайних элементов.
- Не схлопывается.
- Задаёт отступы одновременно по строкам и столбцам.
- Код чище и предсказуемее.
- Работает и в Grid, и в Flexbox.


## 7. Как свойства justify-items и align-items влияют на выравнивание grid-элементов?

justify-items выравнивает содержимое ячеек вдоль горизонтальной оси (по столбцам). Значения: start, end, center, stretch.

align-items выравнивает содержимое ячеек вдоль вертикальной оси (по строкам). Значения те же.

Эти свойства применяются ко всем ячейкам контейнера. Для отдельной ячейки есть justify-self и align-self.


## 8. В чём разница между auto-fill и auto-fit при создании адаптивных сеток?

Обе функции подбирают количество столбцов автоматически по ширине контейнера.

auto-fill создаёт столько столбцов, сколько помещается, даже если они пустые. Пустые столбцы остаются.

auto-fit создаёт столбцы и растягивает существующие, убирая пустые. Если элементов меньше, они растягиваются на всю ширину.

На практике: для карточек чаще используют auto-fit, чтобы элементы занимали всё свободное место.


## 9. Как создать сложные макеты с помощью grid-template-areas и какие правила именования областей существуют?

Макет описывается строками, где каждое имя — область:
grid-template-areas:
  "header header header"
  "sidebar main ads"
  "footer footer footer";

Правила именования:
- Имя — одно слово без пробелов.
- Одинаковые имена в соседних ячейках образуют одну область (должны образовывать прямоугольник).
- Точка . означает пустую ячейку.
- Каждая строка должна содержать одинаковое количество ячеек.

Элементы привязываются через grid-area: header; и т. д.


## 10. Какие преимущества даёт CSS Grid перед другими методами вёрстки для сложных двумерных макетов?

- Двумерность: управление строками и столбцами одновременно.
- Наглядность: макет виден прямо в CSS через grid-template-areas.
- Гибкость: легко переставлять и менять размеры блоков.
- Адаптивность: auto-fit, minmax, auto-fill позволяют строить отзывчивые сетки без медиа-запросов.
- Единая система отступов через gap.
- Меньше обёрток и хаков по сравнению с float и таблицами.
- Хорошо сочетается с Flexbox: Grid — для каркаса страницы, Flexbox — для выстраивания элементов внутри блоков.
